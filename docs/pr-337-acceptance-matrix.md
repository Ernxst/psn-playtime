4. **Accessibility gap (P0):** current component tests do not establish the matrix’s live-region, landmark, dialog/popover name/description, focus-order, mobile sorting, or AT behavior. Semantic snapshots and manual screen-reader-oriented traversal are mandatory, but this remains a structural accessibility review rather than WCAG conformance.
5. **Rendered-media gap (P0):** no current recording proves the candidate-localisation head. Produce fresh matched evidence only after a frozen reviewed SHA and the remediation plan’s recorder smoke test. Do not cite four quarantined stale dashboard recordings.
6. **Excluded evidence scope:** prototype review does not establish production security/threat modelling, external-service resilience, authoritative data correctness, migration compatibility, complete WCAG conformance, cross-browser/device support, performance attribution, operations, i18n/legal governance, final brandmark, or repository-wide code review (`docs/pr-337-remediation-plan.md:292-372`).
